### Deploy to Netlify:
1. Log in to [Netlify](https://app.netlify.com/).
2. Click **Add new site** > **Import an existing project**.
3. Select your GitHub repo `cj-chijioke-electrical-company`.
4. Leave build settings default (Publish directory: `.`).
